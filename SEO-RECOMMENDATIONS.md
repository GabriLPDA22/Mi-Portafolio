## 📋 Próximos Pasos Recomendados

### 1. **Google Search Console**
1. Ve a [Google Search Console](https://search.google.com/search-console)
2. Añade tu propiedad: `https://gabrielcodes.dev`
3. Verifica la propiedad (DNS, HTML tag, o archivo)
4. Envía el sitemap: `https://gabrielcodes.dev/sitemap.xml`

### 2. **Google Analytics 4**
- Instala GA4 para tracking de tráfico
- Configura eventos personalizados (formulario, clicks en proyectos)

### 3. **Imagen Open Graph**
- Crea una imagen OG: `public/img/og-image.jpg` (1200x630px)
- Debe incluir: tu nombre, rol, y diseño premium

### 4. **Performance (Core Web Vitals)**
- ✅ Next.js ya optimiza imágenes automáticamente
- ✅ Fonts con `display: swap`
- Verifica con [PageSpeed Insights](https://pagespeed.web.dev/)

### 5. **Contenido para SEO**
- **Blog opcional**: Artículos sobre desarrollo, React Native, Next.js
- **Case studies**: Detalles técnicos de proyectos (ARCH, Huvegrym)
- **Keywords objetivo**: 
  - "desarrollador full stack freelance"
  - "desarrollador React Native"
  - "desarrollador Next.js"
  - "desarrollo apps móviles"

### 6. **Backlinks y Autoridad**
- Perfil en GitHub (ya lo tienes)
- Perfil en LinkedIn optimizado
- Participa en comunidades técnicas
- Publica proyectos open source

### 7. **Local SEO (Opcional)**
Si quieres aparecer en búsquedas locales:
- Añade ubicación en structured data
- Crea página "Sobre mí" con ubicación
- Perfil en Google Business Profile (si aplica)

### 8. **Verificación de Dominio**
En `app/layout.tsx`, añade códigos de verificación cuando los tengas:
```typescript
verification: {
  google: "tu-codigo-google",
  // yandex: "tu-codigo-yandex",
},
```
